Enterprise Feature Architecture

Built specifically for Windows Administrators, System Integrators, and Managed Service Providers.

01

Deep AppX & Provisioned Purge

Removes bloatware at system root level, preventing pre-installed package re-installation when new user profiles log in.

02

Automated Restore Checkpointing

Automatically triggers a native System Restore Point and registry backup before executing any purging routine.

03

Registry & Orphan File Scrub

Scans HKLM and HKCU registry hives to erase leftover startup keys, orphan service handles, and temp caches.

04

Multi-User & Default Profile Cleaner

Applies purge policies across all offline user hives, default profile templates, and active user accounts simultaneously.

05

Silent Unattended CLI Support

Fully automatable via command-line arguments (`/silent`, `/all`, `/export-log`) for integration with SCCM, Intune, and PDQ Deploy.

Administrator Elevation Bypass

07

Zero Background Footprint

Runs as a single executable without background services, auto-updaters, or resident memory hooks.

Group Policy AD Integration

Audit Logging & CSV Exports

Direct Microsoft API Alignment

6-Step Execution Architecture

The enterprise-grade sequential workflow executed during every purge operation.

Step 01
System Scan
Audits provisioned packages across current and future profiles.
Step 02
Checkpoint
Generates shadow copy and System Restore point for rollback safety.
Step 03
Elevate
Requests SYSTEM level token privileges via WIN32 API.
Step 04
Package Purge
Executes DISM package stripping and AppX unstage tasks.
Step 05
Registry Scrub
Cleans orphan telemetry keys, leftover services, and start menu items.
Step 06
Validate
Verifies integrity of remaining Core Windows OS binaries.
